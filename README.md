# System Design Learning Roadmap

A structured, beginner-to-advanced System Design learning path focused on **LLD, HLD, real-world architecture, and interview preparation**.

> **Learning approach:** Understand the concept → learn why it exists → see the architecture → connect it with real projects → practice interview questions.

## 🧩 Practice Projects

The roadmap will connect System Design concepts to projects that are already familiar:

- **CareerLoop** — job application tracking system
- **CodeBuddy** — developer networking, chat, and subscriptions
- **ShopHub** — e-commerce system

This keeps the learning practical instead of relying only on theoretical examples.

---

## 📌 Lesson Format

Each lesson will keep the same interview-focused structure:

1. Simple explanation
2. Why the concept exists
3. Real-world example
4. Important architecture / diagram
5. Key concepts to remember
6. Interview points
7. Short interview questions

> **Goal:** Learn to reason about architecture and trade-offs, not memorize diagrams.
